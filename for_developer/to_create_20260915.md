## 五、替换后的发布步骤

1. 将设计稿导出为上表所示**同名文件**，覆盖到对应路径（格式：卡面 WebP / 横幅 WebP / logo SVG）；
2. bump 版本号（所有 HTML 的 `?v=bNN` +1，当前 v=b84）：

```bash
cd D:\suveoo\frontend
find . -name "*.html" -exec sed -i "s/v=b84/v=b85/g" {} +
```

3. 上传 R2：

```bash
cd D:\suveoo\backend
node scripts/deploy-frontend.mjs --filter "index.html"
node scripts/deploy-frontend.mjs --filter "assets/images/"
```

4. 无痕窗口访问 /account/cards、/wealth、/about 验证新图生效。
