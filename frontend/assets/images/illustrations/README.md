# 插画规格表（v1 手写 SVG 占位 → 队长精修替换）

日期：2026-09-18（第二十二轮）。设计依据：`notes/webank-design-deconstruct.md`（轻 3D / claymorphism 风：塑料质感、柔和投影、色相与所在渐变卡同族）。

## 替换规则（重要）
- **文件名与引用参数保持不变**：JS/CSS 通过 `文件名?v=bNNN` 引用，替换内容后必须把全站 HTML `?v=bNNN` 递增一位才会对所有用户强制换图（SW 按 URL 缓存，第十七轮踩坑记录）。
- 建议 SVG（任意缩放、体积小）；换 PNG/WebP 时同步改引用扩展名并 bump 版本。
- 透明背景；压彩色渐变卡底的插画（带 `*`）以白色/浅色主体 + 同族点缀设计，保证任意渐变底上可读。

## 建议精修方向（供队长）
1. 统一光源：左上 45°，投影统一 `dy=4-6 / blur=5-6 / 同族深色 25%`。
2. 质感：主体加一条 1-2px 顶部高光（白 80%）模拟塑料边。
3. 色相纪律：每个插画只用一族功能色 + 白 + 金币点缀，不多色混用。
4. 输出后跑 `grep -rh 'v=b1[0-9][0-9]' --include="*.html" -o . | sort | uniq -c` 确认版本唯一。
