## 校准发现（工程经验）

- **Node 24 new Function 表达式体不再返回隐式完成值**——动态求值必须 `"return (" + expr + ")"`
- MCP 确认执行必须从 grant 快照精确复制全部参数（仅加 grant_hash），自组装参数会 CONSENT_INVALIDATED
- SSE 聚合：`type:"token"` 才是文本事件（非 text_delta）
- 登录字段是 `identifier` 非 `email`；OTP 错码真名 OTP_CODE_MISMATCH
- redstep 与 register 场景验证码分池（无 60s 互斥）
- 伪造 grant 连续 4 次触发熔断（计数含伪造=防扫行为）
- userAudit op 返回 `.audit` 数组
- payee add 姓名必须与卡号户名一致（NAME_MISMATCH 守卫）
